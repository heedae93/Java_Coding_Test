# 📚 자료구조와 알고리즘 정리

## 1. 기본 개념

### 자료구조 (Data Structure)

데이터를 효율적으로 **저장하고, 조직하고, 접근**하기 위한 방법.
같은 데이터라도 어떻게 담느냐에 따라 검색·삽입·삭제 속도가 크게 달라진다.

### 알고리즘 (Algorithm)

문제를 해결하기 위한 **명확하고 유한한 절차**.
조건: 입력, 출력, 명확성, 유한성, 효과성

### 둘의 관계

> 💡 **프로그램 = 자료구조 + 알고리즘** (니클라우스 비르트)

- 자료구조: 데이터를 **어디에 어떻게** 담을지
- 알고리즘: 그 데이터로 **어떻게** 문제를 풀지
- 좋은 알고리즘은 알맞은 자료구조 위에서만 성능이 나온다
- 예) "최솟값을 계속 꺼내기" → 배열은 매번 O(N), 힙은 O(log N)

## 2. 자료구조의 분류

```
자료구조
├── 단순 구조   : 정수, 실수, 문자, 문자열 (기본 자료형)
├── 선형 구조   : 데이터가 일렬(1:1)로 연결
│   ├── 배열 (Array)
│   ├── 연결 리스트 (Linked List)
│   ├── 스택 (Stack)
│   ├── 큐 (Queue)
│   └── 덱 (Deque)
├── 비선형 구조 : 데이터가 계층적·망형(1:N, N:M)으로 연결
│   ├── 트리 (Tree)
│   └── 그래프 (Graph)
└── 파일 구조   : 순차 파일, 색인 파일, 직접 파일
```

| 구분 | 선형 구조 | 비선형 구조 |
| --- | --- | --- |
| 연결 관계 | 앞뒤 1:1 | 1:N 또는 N:M |
| 형태 | 일렬로 나열 | 계층(트리) 또는 망(그래프) |
| 순회 | 처음부터 끝까지 한 번에 가능 | 탐색 방법(DFS/BFS 등) 필요 |
| 예 | 배열, 리스트, 스택, 큐, 덱 | 트리, 그래프 |

> 📌 해시 테이블은 분류상 애매하지만 코테·실무에서는 별도 범주로 다룬다.

## 3. 선형 자료구조

### 3-1. 배열 (Array)

- **특징**: 연속된 메모리에 같은 타입 데이터 저장, 인덱스로 바로 접근
- **장점**: 인덱스 접근 O(1), 캐시 효율 좋음
- **단점**: 크기 고정, 중간 삽입·삭제 시 데이터 이동 O(N)
- **적합한 알고리즘**: 정렬, 이분 탐색, 투 포인터, 누적합, 슬라이딩 윈도우, DP 테이블
- **자바**: `int[]`, `ArrayList` (크기 자동 확장)

### 3-2. 연결 리스트 (Linked List)

- **특징**: 각 노드가 `데이터 + 다음 노드 주소(포인터)`를 가짐, 메모리상 흩어져 있음
- **종류**: 단일 연결, 이중 연결, 원형 연결
- **장점**: 위치를 알면 삽입·삭제 O(1), 크기 유동적
- **단점**: 특정 위치 접근 O(N), 포인터만큼 메모리 추가 사용
- **적합한 알고리즘**: 삽입·삭제가 잦은 편집기 커서 문제, LRU 캐시
- **자바**: `LinkedList`

### 3-3. 스택 (Stack)

- **특징**: **LIFO** (Last In First Out), 한쪽 끝(top)에서만 넣고 뺌
- **연산**: `push`, `pop`, `peek` → 모두 O(1)
- **적합한 알고리즘**
    - 괄호 짝 검사
    - 후위 표기식 계산, 중위 → 후위 변환
    - DFS (재귀 대신 명시적 스택)
    - 되돌리기(Undo), 뒤로가기
    - 단조 스택: "오른쪽에서 처음으로 나보다 큰 수" 유형
- **자바**: `ArrayDeque` 권장 (`Stack` 클래스는 구식이라 비권장)

### 3-4. 큐 (Queue)

- **특징**: **FIFO** (First In First Out), 뒤(rear)로 넣고 앞(front)으로 뺌
- **연산**: `offer`, `poll`, `peek` → 모두 O(1)
- **종류**: 선형 큐, 원형 큐, 우선순위 큐 (실제 구현은 힙)
- **적합한 알고리즘**
    - BFS (최단 거리, 레벨 탐색)
    - 위상 정렬
    - 작업 스케줄링, 대기열 시뮬레이션
- **자바**: `ArrayDeque`, `LinkedList` (`Queue` 인터페이스로 사용)

### 3-5. 덱 (Deque)

- **특징**: 양쪽 끝 모두에서 삽입·삭제 가능 (스택 + 큐)
- **적합한 알고리즘**: 슬라이딩 윈도우 최댓값, 0-1 BFS, 회전 문제
- **자바**: `ArrayDeque`

## 4. 비선형 자료구조

### 4-1. 트리 (Tree)

**사이클이 없는 계층 구조**. 루트에서 시작해 부모-자식 관계로 뻗어 나간다.

#### 주요 용어

| 용어 | 의미 |
| --- | --- |
| 루트 (Root) | 최상위 노드 |
| 단말 (Leaf) | 자식이 없는 노드 |
| 차수 (Degree) | 한 노드의 자식 수 |
| 깊이 (Depth) / 레벨 | 루트에서의 거리 |
| 높이 (Height) | 가장 깊은 노드까지의 거리 |

#### 트리의 종류

| 종류 | 특징 | 적합한 용도·알고리즘 |
| --- | --- | --- |
| 이진 트리 | 자식이 최대 2개 | 전위·중위·후위 순회, 수식 트리 |
| 이진 탐색 트리 (BST) | 왼쪽 < 부모 < 오른쪽 | 탐색·삽입·삭제 평균 O(log N) |
| 균형 이진 트리 (AVL, 레드블랙) | 높이를 log N으로 유지 | 최악에도 O(log N), 정렬된 맵 |
| 힙 (Heap) | 완전 이진 트리, 부모가 항상 크거나(최대힙) 작음(최소힙) | 우선순위 큐, 힙 정렬, 다익스트라, K번째 수 |
| 트라이 (Trie) | 문자열을 글자 단위로 저장 | 자동완성, 접두사 검색 |
| 세그먼트 트리 | 구간 정보를 트리로 저장 | 구간 합·최솟값 쿼리 + 값 변경 |

#### 트리 순회

- **전위 (Preorder)**: 루트 → 왼쪽 → 오른쪽
- **중위 (Inorder)**: 왼쪽 → 루트 → 오른쪽 *(BST에서 하면 정렬 순서)*
- **후위 (Postorder)**: 왼쪽 → 오른쪽 → 루트
- **레벨 순회**: BFS로 위층부터

**자바**: `PriorityQueue` (힙), `TreeMap`·`TreeSet` (레드블랙 트리)

### 4-2. 그래프 (Graph)

**정점(Vertex)과 간선(Edge)의 집합**. 사이클이 있을 수 있고 루트 개념이 없다.

> 📌 트리는 그래프의 특수한 형태 (사이클 없는 연결 그래프)

#### 그래프의 종류

- 방향 / 무방향 그래프
- 가중치 / 비가중치 그래프
- 순환 / 비순환 그래프 (DAG: 방향 비순환 그래프)
- 연결 / 비연결 그래프

#### 표현 방법

| 방식 | 공간 | 두 정점 연결 확인 | 인접 정점 순회 | 언제 쓰나 |
| --- | --- | --- | --- | --- |
| 인접 행렬 | O(V²) | O(1) | O(V) | 정점 수 적고 간선 많을 때 |
| 인접 리스트 | O(V+E) | O(차수) | O(차수) | 대부분의 코테 문제 |

#### 그래프 알고리즘

| 문제 유형 | 알고리즘 | 사용 자료구조 |
| --- | --- | --- |
| 연결 여부, 영역 개수 | DFS | 스택 / 재귀 |
| 가중치 없는 최단 거리 | BFS | 큐 |
| 가중치 있는 최단 거리 | 다익스트라 | 우선순위 큐 (힙) |
| 음수 가중치 최단 거리 | 벨만-포드 | 배열 |
| 모든 쌍 최단 거리 | 플로이드-워셜 | 2차원 배열 |
| 최소 신장 트리 (MST) | 크루스칼 / 프림 | 유니온 파인드 / 우선순위 큐 |
| 작업 순서 정하기 | 위상 정렬 | 큐 + 진입차수 배열 |
| 같은 집합 판별, 사이클 검사 | 유니온 파인드 | 배열 |

## 5. 해시 테이블 (Hash Table)

- **특징**: 키를 해시 함수로 변환해 저장 위치를 바로 계산
- **연산**: 검색·삽입·삭제 평균 O(1), 최악 O(N) (충돌이 몰릴 때)
- **충돌 해결**
    - 체이닝: 같은 칸에 리스트로 연결
    - 개방 주소법: 빈 칸을 찾아감
- **적합한 알고리즘**
    - 빈도수 세기
    - 중복 제거, 존재 여부 확인
    - 두 수의 합(Two Sum) 같은 짝 찾기
    - 메모이제이션
- **자바**: `HashMap`, `HashSet`

> ⚠️ 순서가 보장되지 않음 → 정렬된 순서가 필요하면 `TreeMap`

## 6. 자료구조별 시간복잡도 비교

| 자료구조 | 접근 | 탐색 | 삽입 | 삭제 |
| --- | --- | --- | --- | --- |
| 배열 | O(1) | O(N) | O(N) | O(N) |
| 연결 리스트 | O(N) | O(N) | O(1) ※ | O(1) ※ |
| 스택 / 큐 | - | O(N) | O(1) | O(1) |
| 해시 테이블 | - | O(1) 평균 | O(1) 평균 | O(1) 평균 |
| 이진 탐색 트리 | - | O(log N) 평균, O(N) 최악 | 동일 | 동일 |
| 균형 트리 | - | O(log N) | O(log N) | O(log N) |
| 힙 | 최댓값/최솟값 O(1) | O(N) | O(log N) | O(log N) |

※ 삽입·삭제할 위치를 이미 알고 있을 때 기준

## 7. 문제 상황별 자료구조 선택 가이드

| 이런 상황이면 | 자료구조 | 자바 |
| --- | --- | --- |
| 인덱스로 빠르게 접근 | 배열 | `int[]`, `ArrayList` |
| 최근에 넣은 것부터 처리 | 스택 | `ArrayDeque` |
| 먼저 들어온 것부터 처리 | 큐 | `ArrayDeque` |
| 양쪽 끝에서 넣고 빼기 | 덱 | `ArrayDeque` |
| 가장 크거나 작은 값을 반복해서 꺼내기 | 힙 | `PriorityQueue` |
| 존재 여부·개수를 빠르게 확인 | 해시 | `HashSet`, `HashMap` |
| 정렬 상태를 유지하며 검색 | 균형 트리 | `TreeMap`, `TreeSet` |
| 연결 관계, 경로 탐색 | 그래프 | `List<List<Integer>>` |
| 집합 합치기, 같은 그룹 판별 | 유니온 파인드 | `int[] parent` |

## 8. 알고리즘 설계 기법 (참고)

| 기법 | 핵심 아이디어 | 대표 예 |
| --- | --- | --- |
| 완전 탐색 (Brute Force) | 모든 경우를 다 확인 | 순열·조합, 백트래킹 |
| 분할 정복 | 쪼개서 풀고 합침 | 병합 정렬, 퀵 정렬, 이분 탐색 |
| 동적 계획법 (DP) | 작은 문제의 답을 저장해 재사용 | 피보나치, 배낭 문제, LCS |
| 탐욕법 (Greedy) | 매 순간 최선의 선택 | 거스름돈, 회의실 배정, 크루스칼 |
| 백트래킹 | 탐색하다 가망 없으면 되돌아감 | N-Queen, 부분집합 |
